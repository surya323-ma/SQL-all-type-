## ✅ Purpose

- Practice SQL query writing and optimization
- Build strong fundamentals in joins, aggregations, subqueries, and window functions
- Prepare for SQL-based technical interviews

## 🧠 Topics Covered

- SELECT, WHERE, GROUP BY, HAVING
- Joins (INNER, LEFT, RIGHT, SELF)
- Subqueries & CTEs
- Window Functions (RANK, ROW_NUMBER, LAG/LEAD)
- Aggregate Functions
- String & Date Functions
- And more...

## 💡 How to Use

1. Browse the repo and search by problem number or title.
2. Open the `.sql` file to view the query solution.
3. Check comments inside for logic/approach.
